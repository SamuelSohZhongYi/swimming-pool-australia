# Making a Splash: Public Swimming Pools Across Australia

FIT3179 Data Visualisation 2 · Samuel Soh Zhong Yi (34076808) · Monash University Malaysia · October 2026

| Folder | Contents |
|---|---|
| `index.html` | The visualisation page (one scrolling page, 8 sections) |
| `css/style.css` | Layout, typography and colours |
| `js/` | One Vega-Lite specification (`.vg.json`) per chart, human-readable |
